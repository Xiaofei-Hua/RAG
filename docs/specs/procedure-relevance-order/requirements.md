# Requirements

## Need and Scope
用户明确确认继续修复中文流程无关内容与首节顺序，不增加模型调用；设计与独立评审后编码，真实多轮、新留出无实质退步才默认启用，更新文档并合并main。表面问题是墙钟/年鉴混入首节，本质是流程选择必须由用户需求驱动，并遵守用户指定的信息顺序。沿用16GB/Qwen3.5:9b、一次最终生成，不改普通比较/改写/检索策略。

## EARS
- REQ-701: WHEN生成流程说明，系统SHALL只选择回答用户所问事项的依据，保留相关的限制/未知信息/目的，不因共同实体或同一资料来源引入无关事实。
- REQ-702: WHEN用户指定先交代主要规则和范围，系统SHALL在可见首节实际给出这些规则和范围，并在后续按所问流程说明动作、条件、分支、记录与用途；全文与首节分别验收。
- REQ-703: WHEN优化进入Fast或Thinking，系统SHALL保持一次最终生成、原预算/none/温度/输出检查、真实来源和完成性/取消契约；未支持或失败继续原有降级，None不作0；不追加生成/验证调用。
- REQ-704: WHEN验证质量与性能，系统SHALL把已公开留出退为开发，保留全部对照结果，在候选冻结后创建新的独立留出，多轮核对完整语义、首节、调用和时间；实质退步不能用总分或速度抵消。
- REQ-705: WHEN开发与新留出证明被改路径无实质退步且不增调用，系统SHALL仅对合格本地流程更新默认并同步文档/回滚；否则仍false并继续定位，不将测试结构合法冒充质量证明。
